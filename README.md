# Gallery Eksen 11

Website galeri karya untuk pameran Eksen 11 — menampilkan karya dari open
submission dan kolaborasi antar UKM. Pengunjung bisa melihat daftar karya dan
menyaringnya berdasarkan kategori. Ada halaman admin terpisah untuk
menambah, mengedit, menghapus karya, dan menandai status terjual/tersedia.

## Screenshot

![Tampilan Gallery Eksen 11](screenshots/home.png)

## Fitur

- Halaman publik (`index.html`) menampilkan galeri karya dengan filter kategori
- Halaman admin (`admin.html`) untuk kelola data karya (tambah, edit, hapus, tandai status)
- Responsive untuk mobile, tablet, dan desktop
- Dibangun dengan HTML, CSS (plain, tanpa framework), dan JavaScript (DOM manipulation)

## Teknologi

- HTML5
- CSS3 (plain CSS, tanpa Tailwind/Bootstrap)
- JavaScript (vanilla, manipulasi DOM, localStorage)

## Cara Menjalankan

1. Clone repo ini
2. Buka folder di VS Code
3. Jalankan `index.html` lewat extension Live Server
